\section{What is already true without running anything}
\label{sec:zerocompute}

Everything above rests on measurements a reader has to take on trust until the
data is inspected. This section does not. Table~\ref{tab:zero} lists nine
checks on the public repository at the pinned commit, each checkable in a few
minutes, each bearing on whether two entries on one leaderboard are comparable.
The first seven require reading code or repository history; the last two are
computed from public trajectories, and the final row is an inference rather
than a read fact. We re-verified all nine against commit \texttt{83e7b8fc}
while drafting.

None of this requires trusting a measurement of ours. The first seven rows
require reading the repository; the last two are computed from public
trajectories. One nuance is empirical rather than read from code: the 30 runs
above the cap sit at 51--54, and a plausible innocent cause is a custom agent
setting its own bound --- whichever it is, the board does not say.

discussion. We will update the repository README as these move.
